PhishGuard 6.1 — Deep Scan

1. Сохраните резервную копию рабочей папки phishing-project.
2. Распакуйте файлы из архива в phishing-project с заменой index.html, style.css, script.js и server.py.
3. Оставьте свой локальный .env без изменений. В архиве его нет!
4. В терминале VS Code в папке проекта запустите: py server.py
5. Откройте сайт в Chrome: http://127.0.0.1:5000/
   НЕ открывайте index.html двойным щелчком (file://): онлайн-функции не заработают.
6. Откройте «Анализатор», введите https://example.com/, подтвердите согласие и нажмите «Запустить глубокую проверку».
7. Подождите ~30–120 секунд. Скриншот появится в блоке Deep Scan, если сервис его предоставил.

Важно:
- Для онлайн-сканирования требуется интернет и действующий ключ URLSCAN_API_KEY в .env.
- Адрес отправляется третьей стороне urlscan.io с видимостью unlisted, НЕ полностью приватно.
- Не отправляйте ссылки с личными данными, токенами и приватные адреса.
- Сервис имеет лимиты; отсутствие предупреждения о вредоносности не означает безопасность.
- Локальный анализ адреса, тренажёр и база знаний работают отдельно.
- Этот Flask-сервер предназначен только для локальной разработки (127.0.0.1), не для публичного хостинга.

PhishGuard 6.2: ожидание до ~3.5 минут, повторные запросы результатов при временных ошибках; повторное нажатие для того же URL использует прежний scan_id. API-ключ передаётся при запросах результатов и скриншотов.


6.3: фирменный favicon, навигационные кнопки и действия, распознавание localhost/127.0.0.1, блокировка удалённой проверки loopback. API-ключ хранится только в локальном .env.
