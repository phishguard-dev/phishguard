PhishGuard 7.0 - package for Render

1. Do NOT upload .env or API keys to GitHub.
2. Create a private GitHub repository and upload the project files.
3. In Render: New > Blueprint, connect repo, use render.yaml.
4. Set URLSCAN_API_KEY as secret environment variable in Render.
5. Deploy, open your .onrender.com URL and test.
6. Free plan may sleep; check current Render pricing/availability.
7. This release uses in-memory rate limiting, not durable or distributed.
8. Do not submit private links or links with personal tokens to Deep Scan.
